# А2-ИНВЕСТ

Статическая копия сайта `a2-invest.ru` с очищенной вёрсткой (без водяных знаков и блокировок конструктора Рег.ру) и рабочей формой обратной связи.

## Что изменено
- Удалён виджет-вотермарка Рег.ру и мета-тег `generator`, снята блокировка формы (`Этому плагину требуется обновление плана`).
- Все стили, шрифты и изображения локализованы внутри репозитория, исправлены относительные пути для работы на GitHub Pages (включая подпапки `О-нас/` и `Контакты/`).
- Реализована рабочая и доступная форма обратной связи (`css/form-enhancements.css`, `js/contact-form.js`):
  - клиентская и семантическая валидация (`aria-invalid`, `aria-describedby`, `aria-live`), защита от ботов (honeypot `_honey`),
  - отправка заявок через AJAX на `https://formsubmit.co/ajax/a2-invest@mail.ru` (при первой отправке FormSubmit пришлёт письмо на `a2-invest@mail.ru` для однократного подтверждения адреса; при желании можно указать свой endpoint в атрибуте `data-endpoint` у `<form>`),
  - резервная кнопка отправки через почтовый клиент (`mailto:a2-invest@mail.ru`) с предзаполненными полями, если сеть недоступна.
